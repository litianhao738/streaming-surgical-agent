# 单模型五专家 A/B/C 诊断实验

## 直白结论

五次API对某些任务有帮助，但没有解决完整五头预测。C组找回了两个null IVT，部分Verb与Phase更好；Target依然0/6完全匹配，I/V/T/IVT齐全的五帧中四帧不满足组件包含关系。当前不宜把五个独立专家直接接成最终答案。

补充null语义的B组没有显示出收益，但它的非null片段全部输出失败，不能据此宣称prompt定义无用或模型能力已被完全定位。没有在看到答案后修改任何提示、补发请求或修复输出。

## 预先固定的实验设计

- 单一模型：OpenRouter `qwen/qwen3.8-max-0902`；Alibaba限定路由，无fallback。
- Validation VID110两个新片段：6251/6276/6301及8501/8526/8551。每个目标输入t-50/t-25/t三张因果图。
- 选择方式：在调用前查看GT以分层选择诊断片段；两帧null-only、一帧混合、三帧non-null-only，覆盖阶段0/1。这不是随机或代表性抽样。
- GT分层选择与推理隔离：推理请求没有GT、GT框、其他专家预测。所有结果冻结后才加载GT评分。
- A：原五头联合预测，带schema版本号澄清与top-k。
- B：A + 通用本体边界说明，不加入帧特定提示。
- C：与B相同的本体说明和视觉输入，每个任务各一次独立调用；只返回该任务的selected和top-k。五专家不交换预测、不投票、不做修复。
- 每项top-k仍为I3/V4/T5/IVT8/P3。共享完整本体、医学背景、max_output_tokens4096、reasoning low。
- 并发上限4；逐目标轮换A/B/C入队顺序；每请求最多一次provider调用，0重试。A6+B6+C30=42次。
- C的总调用和推理预算大于A/B；即便有收益，也不能仅归因于任务拆分而排除额外计算量。
- 本地payload记录history low/target auto。但进一步检查OpenRouter `_request_body` 发现当前未转发image_details，因此不能把实际provider侧detail声明为low/auto已生效。三组使用同一传输路径及图像字节，此点不构成组间差异；本轮未改传输。

本体边界说明依据[CholecTriplet官方FAQ](https://cholectriplet2021.grand-challenge.org/FAQ/)：null包括不在规定动作、靶点或联合组合中的交互，不必然表示没有物理动作。完整新增文本及42个请求hash已在调用前写入plan.json。

每个单元格为“完全匹配帧数 / 该项有效响应帧数”。所有任务GT分母均为6；失败不是空标签，也不记为正确。

## 单项正确不等于联合正确

闭包定义分开报告：

1. 组件包含：每个selected IVT的I/V/T必须在对应selected字段中。
2. 严格投影相等：I/V/T集合与所有selected IVT组件的投影完全相同。

| 组别 | I/V/T/IVT齐全帧 | 组件包含通过 | 严格投影相等 |
|---|---:|---:|---:|
| A | 5 | 5/5 | 0/5 |
| B | 3 | 3/3 | 2/3 |
| C | 5 | 1/5 | 0/5 |

最明确的案例：6251，GT为I=[2], V=[9], T=[14], IVT=[96], P=[0]。

- C Instrument=[2]，正确。
- C IVT=[96]，正确；其组件是(2,9,14)。
- C Verb=[2]，Target=[11,10,0]，既不匹配GT，也不能与IVT96闭包。
- C Phase=[0]，正确。

这证实了拆分能找回部分答案，同时也能制造互相矛盾的五头输出。闭包检查只报告冲突，没有把IVT反投影到其他字段，也没有删除或替换原始预测。结构合法本身也不保证语义正确：A组件包含5/5通过但IVT仍0/5。

## 响应失败诊断

- A8501、B8526、B8551：原始JSON只包含schema_version和instrument，缺少另外四项；按strict schema拒绝。原始JSON已保留，未局部补成有效联合响应。
- B8501、C6276-phase、C6301-instrument/verb、C8526-phase、C8551-phase：ledger为response_content_invalid，在生成有效ProviderResponse前失败，没有可评分完整JSON，费用未取到。
- 针对实际OpenRouter body构建增加离线回归测试：A/B要求全部五头，C只要求单一任务。各schema隔离，未发现本地专家schema污染联合schema。响应失败的服务端更深原因未查明，不将其全部归为视觉能力不足。

## 对下一步的判断

暂不全面切换五个独立专家。当前数据支持“部分任务可从独立调用受益”，不支持“完整五头已修好”。主要剩余点为Target语义定位、跨头关联和响应合同可靠性；仅补一段null说明不足以解决。

若继续推进，应先分清Target的候选召回/排序/视觉接触关联，再设计共享实例级关联的方案。不能在这些已看过GT的六帧上反复优化后宣称泛化收益。无需因本次结果立即启动Gate训练。
