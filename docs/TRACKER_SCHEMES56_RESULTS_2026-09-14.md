## 方案 5：没有可归因的精度收益

整体 F1 +0.4026 点，但错漏 +2，VID23 和 VID31 变差，未通过错漏与逐视频检查。

关键事实：16 帧中只有 VID96_23151 的先验提示真正改变；该帧最终预测完全相同，错漏都是 4，F1 都是 53.3333。其余 15 帧请求提示相同但分别重采，整体差异可能来自模型输出随机性和回复有效性变化，不能当成 Tracker 的贡献。

候选池对 GT IVT 的覆盖为对照 11/30、方案 5 为 12/30，但同样不能忽略上述同请求重采因素而作因果归因。本小试验对先验扩展的有效样本只有 1 帧，不足以否定这一方向，也没有支持推广的证据。

## 方案 6：Qwen 提示改变了判断，最终多漏一个 target

整体 F1 -0.5732 点，错漏 +1；instrument、verb、IVT、phase 均与对照相同，target F1 从 53.8462 降至 50.9804。VID96 变差，其余三个视频结果相同。

唯一最终预测差异在 VID96_15526：对照 target=[0,1]，Tracker-Qwen target=[1]，漏掉 GT target 0。该帧 Gate 两组都选择交互审核，因此不能解释为 Gate 误跳过审核。

保存的 Qwen 回复显示，target_0 从 rating=5/MATCH 变为 rating=4/VISIBLE_ONLY；其他器械、动作和 IVT 判断也发生变化。随后原早停逻辑将该帧从 7 次逻辑调用缩短为 5 次，最终返回缺少 target 0 的结果。此处描述的是已观察到的回复与执行路径，不把模型解释当成视觉事实，也不声称单次配对证明稳定因果效应。

总体上，Qwen 提示影响了 Gate 分数及早停路径，说明 Tracker 信息确实进入系统；本次并未带来精度提升。
