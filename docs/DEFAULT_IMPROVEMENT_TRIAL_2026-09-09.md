# 默认图谱＋Phase方案：候选、Verifier与Repair分开对照

本轮用户授权尝试多种方案完善默认版。原默认版本、H0协议、所有历史分数均冻结保留。

**版本口径纠正：本轮control实际调用原始审核提示，不是当前默认的精简提示。** 源码直接导入原`review_wire`和`phase_wire`；冻结目录中的默认配置虽指向精简版，但实验入口没有读取它来切换提示。下文的control均指“原提示图谱＋Phase对照”，不能冒充精简默认版的新24目标成绩。它与各实验变体的内部配对仍有效。最后另用精简版归档回答检查加权审核的适配，没有据此替换默认。

## 预先固定的对照

| 方案 | 修改位置 | 保持固定 |

ROI来自已核验的corrected OOF预测框，只表示可能的器械区域。按预测分数≥0.5取最多两框，固定扩展35%且每侧至少图像尺寸6%；模型不接收Tracker类别、分数或轨迹ID。不是器械末端或接触点真值。三帧条带使用同一图像坐标，不声称是同一组织或匹配轨迹。VID31使用未在其器械实例标注上训练的full模型预测，该视频没有可评器械框GT。

Verifier保留三张图及原图像索引：前两张历史不变；第2号目标图左侧完整原图像素不缩小，右侧加入局部放大视图。输入明确要求检查完整场景后才可判断整帧不存在。模型的视觉判断仍可能错误。

## 样本、预算和判定

开发阶段使用历史八目标及缓存H0、缓存的独立Phase原始回答；三个补候选方案顺序按目标轮换，Verifier放大对照在其后执行。完全相同的候选／审核请求在同目标内复用回答，包括失败。最多184次新POST，OpenRouter $3、xAI $2、阿里云¥2。

确认阶段已独立冻结24个新Training目标，每视频六个时间分位，距离所有归档／计划目标和历史图像身份大于250原视频帧。只看时间、媒体可用性及任务mask选样，不用GT标签值；视频仍来自已用过的四个Training视频，不是新视频泛化。最多选择一个开发方案与默认对照，重跑共享H0、共享独立Phase及必要补候选／审核，最多432次POST，OpenRouter $6、xAI $4、阿里云¥4。没有Testing调参、追加重试或数据替换。

选用条件：相对同批control，五头等权平均F1严格提高，IVT F1和五头平均Precision不下降，总FP+FN减少且有实际有益修改。按平均F1、IVT F1、固定方案顺序选一个方案；新目标确认使用同一规则，不在看结果后改阈值或提示。接口均可用子集另报，不取代完整样本主结果。Phase五头合并对所有变体共享，不能把Phase独立收益算成四头改动收益。

入口：`scripts/run_default_improvement_trial.py`。开发目录：`artifacts/preflight/default_improvement_dev_20260909_v1/`。新目标选择：`artifacts/preflight/default_improvement_inputs_20260909_v1/selection.json`。

本轮ROI属于新增Tracker定位依赖。如果以后采用，必须在Tracker消融中明确禁用该输入，不能把使用OOF框的方案写成“无Tracker”。新入口和模型实验仍与原默认版隔离。
