- 每目标 AB/BA 交替，四路并发，完成顺序不受控。24 目标 × 2 组 = 48 调用；零自动推理重试，独立本地缓存和防重复锁。预计约 $0.60，规划上限 $0.85，每个在途调用预留 $0.05；不是提供商美元硬限额。

## 决策

不采用删 Schema 版替换原版，暂停把它当作“提高效果同时降本”的推荐方案。本轮未通过预先冻结的采用门槛：五头 F1 均低于原版，Verb/IVT/Phase 整组正确及五头同时正确也下降。

结论限于当前模型、三帧输入和这些开发目标。每组每目标仅单次生成，temperature 0 不保证确定性；四个视频的小规模对照不能证明重复 Schema 在所有任务中必然有效。但现有证据足够支持保留原版，而不是因为输入 token 较少就切换。

没有额外训练或继续启动新的付费实验。原版、候选、此前精调失败版本和全部原始结果均保留。
