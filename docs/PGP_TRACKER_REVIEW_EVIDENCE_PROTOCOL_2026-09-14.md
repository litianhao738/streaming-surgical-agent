# Tracker 作为审核证据：冻结模型配对小批协议

使用当前默认 Qwen PGP-Gate 和已冻结的 Tracker OOF 权重，不重新训练或调阈值。Tracker 不进入 H0、候选建议、Qwen 初审或 Gate 特征，只给 Gate 放行之后的剩余四位交互审核员提供器械位置、类别假设、置信度和三帧关联 ID。阶段分支保持原样。本协议在读取新实验的 GT 结果前冻结。

固定抽样 64 帧，每个 Training 视频 16 帧。仅要求冻结 Gate 放行、Qwen 初审后仍有交互候选未确定；此条件在后续审核前可知。对符合条件的帧按时间排序取 16 个均匀分位位置，不按 GT、修复结果或 Tracker 与标签是否一致筛样本。

每帧两组：重新请求无轨迹证据的对照，以及带轨迹证据的处理。顺序按样本轮次交替，同一帧使用相同 H0、候选池、图像、初审回答、模型、参数、输出格式和阶段回答；唯一请求差异是两项新增的 Tracker 提示字段。Qwen 初审已支付并复用，不再重复询问。只改变后续四位交互席，最多每组四次请求，不增加审核轮次；完整采集支持各组按既有精确早停规则独立回放。

证据最多每帧 6 个器械，取冻结预测置信度最高的项目；框采用原图归一化坐标，仅使用当前及前两帧。原始轨迹 ID 映射为局部 T1/T2 等，不传递任意文本、真值、训练元数据、其他审核员意见或新候选。明确告知审核员以画面为准，检测类别/轨迹不证明动作或接触目标，漏检不能证明整帧不存在。

先执行 8 帧技术检查，确认路由、格式及上下文生效后完成固定 64 帧；不根据这 8 帧的标签表现更改提示或抽样。最多 512 次新请求，OpenRouter 预算 $5，GLM 和 DeepSeek 各不超过 128 次，其余账户为零。不自动重试，不删除失败样本。若技术失败或路由不可用则停止，不用替代模型悄悄补齐。

预定小批筛选条件：处理组五头平均 F1 不下降、FP+FN 不增加，至少一项严格改善；每个视频同样不恶化；包含附加输入及实际早停路径的已知美元推理成本不超过对照 10%。同时报告合并口径、改好/改坏帧、调用数和各提供方请求数量。输入 token 不视为免费，GLM/DeepSeek 暂按请求配额报告，不能把这些账户说成零成本。

此为固定最终 Gate 选出的 Training 子集上的条件性机制试验。即使筛选通过，也只支持开展更大规模确认，不直接替换默认或声称论文级稳定提升；如果无改善或有伤害，则保留结果、不扩大付费采集。
