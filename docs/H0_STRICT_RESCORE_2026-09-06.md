# 40 目标严格重算 F1 与 Accuracy

已从 80 份保存的 HTTP/SSE 原始返回中独立重建可见 JSON，并重新读取源 GT。原版与只删 Schema 版各 40 个目标，未重新调用模型，新增 API 费用为零。

本轮加强原始证据核查：检查正常结束、指定模型、JSON 重复键、完整五头、ID 类型与范围、重复 ID；只有可见回答进入评分，推理文本不进入预测。80/80 份返回均通过，重建预测与旧记录全部一致。

按任务独立检查有效性；缺失 GT 不进入该头的分母。VID103/VID23/VID96 从实际逐实例字段聚合，VID31 使用已有明确来源的动作和 Phase 修复文件。40 目标五头 GT 全有效，未发现与保存 GT/mask 的差异；源文件及旧预测、汇总在重算前后哈希一致。

计分定义：
- micro-F1 = 2TP / (2TP + FP + FN)。IVT 必须整个类别/三元组匹配才获得 TP；一个组件正确不获得 IVT 部分分。多报计 FP，漏报计 FN。
- 每头 Accuracy 使用集合完全匹配率：多报、漏报或错报任意一个标签，该帧该头均不算完全正确。
- 有效 null 类保留；完整标注但模型失败仍计入分母。五头联合 Accuracy 只在五头 GT 全有效的目标中计算。
- F1 依然会累计正确标签。例如 GT=[17]、预测=[17,60]，TP=1、FP=1，因此该帧标签 F1 为 2/3，但集合 Accuracy 为 0。不能把全有或全无的帧正确率另称为标准 F1。
