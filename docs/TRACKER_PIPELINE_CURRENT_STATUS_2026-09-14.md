## 最新建议：优先采用 v2 方向，先保留原 Gate

相较此前只修正器械头的方案，Claude 的出口融合、动作先验和阶段滤波更符合“零新增 LLM 调用、提高最终精度”的目标。建议首先将 **M1–M4 作为独立研究版本，保留原 Gate 模型和路由**；M5 重训作为进一步节费的优化项。

这是一项待执行的建议，不是用户已批准的实现或默认选择。原器械融合保留为保守对照。

```text
原 H0 → 原 proposal / 先验 → 原 Qwen 初审 → 原 PGP-Gate
                                            ├─ 跳过：便宜答案
                                            └─ 放行：原交互审核 + 精确早停 + 歧义回滚
                       ↓
M1 当前帧 Tracker 器械集合替换 + 不兼容 IVT 过滤
                       ↓
M2 三条器械条件动作先验补充
                       ↓
M3 便宜档原始阶段预测的因果窗口滤波
                       ↓
五头输出（M4 跳过原阶段推荐和审核分支）
```

M1/M2 放在原审核后，不修改现有 LLM 输入，因此可以先使用缓存开展零 API 研究。M4 需要独立运行时支持 action=1；当前运行时仍只接受 action=0/3。

## 评审发现：执行前需要明确或修正

1. **M1 硬删除的风险和歧义保护边界。** Tracker 漏检会连带删除正确 IVT。M1 在歧义回滚之后执行，也可能删除刚恢复的 grasp/retract IVT；保留的是审核层的保护规则，不是最终这些 IVT 一律不变。必须分别统计删除正确/错误 IVT 和召回变化。
2. **M2 是共现先验，不是确定动作。** 规则统计的是 P(帧中有动作 | 帧中有器械)，不是实例级动作归属。应称“器械条件动作先验补充”；三条规则为 clipper→clip、hook→dissect、scissors→cut。排除 grasp/retract 属于已有结果之后的选择，独立验证时须冻结规则。
3. **阶段滤波存在文档/代码差异。** 文档称平局保留当前阶段；脚本仅在当前阶段属于并列众数时保留，否则取第一个众数。脚本使用历史原始 cheap Phase，不能实现成历史滤波结果的递归投票。需明确时间窗口边界、缺帧和视频状态重置。
4. **阶段选择与延迟尚未闭环。** 83.9577 是三个外层选择 60 秒、VID31 外层选择 30 秒的汇总。固定 60 秒的 85.2286 是同一开发集上的另一结果，不是同一验收口径。稀疏缓存到连续 1 fps 输出的差异，以及阶段切换延迟，都尚未完成独立实测。
5. **整条链路未完全嵌套。** Gate 层有内外层划分，但复用的上游先验、Tracker 和缓存没有随 Gate 每个外层完全重新生成。M2 规则按每行所属视频预先留一统计，也没有随 Gate 外层重新隔离。四折规则一致是有利证据，不能替代整条链路的隔离证明；原保守方案也有上游未完全嵌套的限制。
6. **输出契约和不可用回退尚未实现。** 原输出最多允许 3 种器械、4 种动作。v2 探针直接使用集合算分，没有最终 schema 校验；器械替换或动作追加需处理超限。Tracker 缺失时直接字典索引，尚未实现文档所述回退。正常空检测与读取失败必须区分。
7. **论文比较仍不完整。** Tracker×PGP 的四格需统一审核范围和阶段滤波设置；应同时比较实际调用/费用和审核比例。逐视频 top-k 的成本曲线是离线排序诊断，不是已验证的在线固定阈值策略。最终全量拟合 Gate v2 的阈值表现必须另报。

阶段滤波相对原 PGP 的阶段头改善约贡献 2.03 个五头平均 F1 点，接近总提升的一半，应独立归因。M1/M2 不消费跨帧 ID，不能据此声称时序关联提高关系识别。Target 没有直接补充路径；现有方案仍未解决缺失 IVT 候选和同类多实例关系绑定的问题。
