# 40 目标 GT 缺失、分母和低分口径核查

结论：缺失 GT 应按任务分别排除，已有通用评分代码已经这样处理。本次 40 目标的五头 GT 全有效，未发现源标注与评分 GT/mask 不一致，分母仍为各 40，重算后成绩不变。没有新的付费调用，也没有修改原始预测、标注、冻结版本或评分规则。

## 分母的正确含义

任务的整组完全匹配率 = 在该任务 GT 有效的目标中，预测集合完全匹配 GT 的帧数 / 该任务 GT 有效的帧数。

若第 5 帧只有 IVT 缺失而 Phase 有效，IVT 分母为 39，Phase 分母仍为 40；只有 Phase 自己缺失，Phase 分母才减为 39。若同时统计“五头全部正确”，该帧因为五头不全而不能参加五头联合评估，但其他有标注的头仍可各自计分。

须区分：

- 缺失/未知标注：按任务 mask 排除。
- 明确标注为没有正类的有效空集合：不是缺失，按该任务定义计分。
- `null_verb`、`null_target`、IVT 94–99：项目本体中的有效类别，不是缺失 GT。
- 调用失败：如果 GT 有效，失败仍留在分母，避免只对成功返回计分的偏差。

## 分数低体现什么

此前简称 Accuracy 的指标实际是**每头的标签集合完全匹配率（set exact / subset accuracy）**。例如 GT 为 `[17]` 而预测 `[17,60]`，虽然命中了 17，但多报 60，整组计错；micro-F1 则保留部分命中的贡献。以后应完整标注这个名称，避免与单标签准确率混淆。

本次原版 IVT 的 40 帧构成为：

- 整组完全正确：4 帧。
- 有正确标签但未整组匹配：14 帧。
- 没有任何正确 IVT 标签：22 帧。

原版 IVT 全部标签计数：TP=22、FP=46、FN=42，因此 F1=33.33%。这说明低分不能只归因于严格的整组指标，误报和漏报也较多。GT 中有 7 个 null IVT 标签，原版与删 Schema 版均未命中；这些是有效标签的识别错误，不应按缺失删除。

Phase 是单标签任务，原版 17/40=42.50% 就是阶段预测正确率；它的低分无法用多标签完全匹配规则解释。此次审计排除了这 40 目标的缺失 GT 分母问题，不等于已经定位所有视觉识别错误，也不等于重新证明全部源数据标注绝对正确。
