# 方案 4 实现与离线验证结果

## 结论

方案 4 已实现为独立研究版本，6059 帧 Training 缓存回放通过。实际发送 API 请求 0 次，两个默认版本文件未变。

| 版本 | 五头平均 F1（%） | 错漏 FP+FN | 回放逻辑调用 |
|---|---:|---:|---:|
| 原 PGP | 61.6989 | 36150 | 37157 |
| M1–M4，保留旧 Gate 外层路由 | 66.3858 | 32423 | 26647 |
| M1–M5，Gate v2 嵌套外层 | 66.3849 | 32427 | 24047 |
| Gate v2 全量模型在训练集回放 | 66.4002 | 32398 | 23600 |

完整 v2 外层比原 PGP 增加 4.6860 个百分点，逻辑调用减少约 35.28%。重训 Gate 的主要收益是减少调用：相对旧 Gate 的 M1–M4，再少 2600 次，精度基本持平且错漏增加 4。全量拟合结果不能替代外层结果。

## 实际 pipeline

原 H0 → 原候选提议 → 原 Qwen 初审及 42 维特征 → Gate 选择跳过或只做交互审核 → 保留原交互聚合、早停及歧义回滚 → Tracker 器械替换与不兼容 IVT 过滤 → 三条器械动作先验 → 因果阶段滤波 → schema 校验输出。

Tracker 无效时回退；有效空检测与不可用明确区分。器械超过 schema 容量时回退整个 M1/M2，动作超限只回退 M2。6059 帧中器械容量回退 1 次、动作容量回退 1 次，Tracker 不可用 0 次。

阶段采用原 cheap 阶段输出，在 (t-W,t] 秒内对原始阶段投票，最高票平局保持当前原始阶段。每个视频隔离状态，禁止未来帧、重复帧、乱序帧和递归投票。窗口从预先规定的 0/5/10/20/30/60 秒中仅用其他视频选取；四个外层折均选 60 秒。

## 增益归属与风险

| 头 | 原 PGP F1 | v2 外层 F1 |
|---|---:|---:|
| instrument | 86.8284 | 93.9889 |
| verb | 60.8594 | 64.9887 |
| target | 50.6759 | 50.6684 |
| IVT | 36.3398 | 36.9343 |
| phase | 73.7911 | 85.3441 |

不能把全部增益都归于 Tracker。固定旧交互 Gate 与相同 Phase 设置的消融中，加入 Tracker M1/M2：64.0095 → 66.3858，约 +2.3763 点。固定 Tracker 与 Gate，阶段滤波：64.0092 → 66.3858，约 +2.3766 点。阶段滤波属于独立时序模块；target 没有得到直接修复。

旧 Gate 的 M1/M2 路线上，过滤删除 622 个错误 IVT，也误删 69 个正确 IVT。器械存在不等于动作发生，三条规则仍可能增加假阳性，不能宣称无条件正确。

18 个可观测阶段转换中，滤波后 15 个在对应阶段片段内命中，3 个片段未命中；已命中的转换相对首次观测新 GT 的延迟中位数 11 秒、P90 34.8 秒。原 cheap 对应为 18 个命中、中位数 0 秒。边界采样间隔最大达 153 秒，这些只是稀疏回放观测，不能代表完整视频实时延迟。现阶段不宜自动替换默认 Phase。
