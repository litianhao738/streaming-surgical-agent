## 问题与预先冻结的设计

删除提示词里的重复 JSON Schema 不能预先保证无影响。API 的严格 response_format 保留，只能说明输出约束没有主动删除；字段合法与五头语义正确必须分别验证。五头 GT 齐全描述的是评分覆盖，不代表全部类别都出现，也不意味着结构约束能解决视觉识别。

- 模型：OpenRouter `qwen/qwen3.8-max-0902`，严格 Alibaba 路由，temperature 0、reasoning low、max_tokens 4096。
- 输入：同一目标的 `[t-50,t-25,t]`，对应 `[-2,-1,0]` 秒；历史图 low detail、目标图 high detail。只预测目标帧。
- 固定样本：旧 80 目标冻结计划中，VID103、VID23、VID31、VID96 各取排序位置 9、12、15、18（零起算），共 16 目标。先固定位置，再检查五头 mask；不按 GT 类别或预测对错排名，不换样补齐。
- 来源：Training 开发样本。未参加先前已完成的窗口实验前 32 目标或保守精简 8 目标付费预测，但旧中断实验曾离线评分冻结目标，不能称从未接触 GT 的独立测试集。
- 三组：baseline 原始提示词；schema_only 只删除系统末尾完整 Schema 并提示遵循 response_format；tuned 在 schema_only 方向上清理空状态/重复帧号，并改写逐器械证据组织。
- 完整保留五头、100 类 IVT 映射、原 null/OOV 边界和结构化输出 Schema；不增加 Tracker、Repair、循环或跨窗口状态，不训练模型。
- 每目标三组调用顺序轮换，全部请求与图片哈希在推理前冻结。48 次调用，无自动推理重试。预计约 $0.60，规划支出上限 $0.85；每个在途调用预留 $0.05。软件支出检查不是提供商强制美元硬限额。

本轮不同时测试 minimal，也不更换图片、模型或输出 Schema。

## 精调内容与依据

1. 由目标图确认器械当前存在；历史可见不自动代表目标时刻仍可见。
2. 用器械互动与因果变化判断当前动作；提醒相机视点变化和稀疏采样的局限。
3. 判断器械实际作用的解剖结构、材料或区域；使用接触或其他可见动作证据，避免把附近组织仅因邻近而另报为靶点。
4. 建立器械、动作、靶点关联并匹配 IVT，汇总帧级标签、判断阶段。常见阶段本身不足以确认一个具体互动。

以上是待测的证据使用提示，不是新制定的标注规则。尤其不添加“静止即 grasp”“某器械配某组织必为某动作”等特判。精调没有要求 I/V/T 必须等于 IVT 投影；保持原提示词中的单向组件包含约束。

[CholecTriplet2021 官方挑战论文](https://arxiv.org/html/2204.04746v2) §3.1、§3.3、§3.4 支持逐帧关联、多实例多标签和因果输入；§6.3 提及抽吸与冲洗中的流体时序动态。它未提供本轮可直接采用的 grasp/retract 冲突裁决表。旧官方 FAQ 本次访问失败。保留项目原 null/OOV 提示词不等于重新证实其全部官方解释。

## 预注册评价与采用规则

- 格式：合法五头结构返回率、缺字段/类型/枚举/截断失败；失败保留在全部目标分母。
- 语义：五头各自集合 exact、micro-Precision/Recall/F1，五头同时 exact，逐视频与共同成功目标配对结果。缺失标注按 mask；本实验固定目标应五头均有效。
- 结构：IVT 组件包含及严格投影闭包另报，不能替代语义效果。
- 成本：原始输入、推理、可见 JSON、缓存读写 token、实际费用和无缓存单价等效费用，分别报告，避免缓存命中差异被误判为文字精简收益。
- 候选只有合法返回率、五头各自 F1 和 exact、五头同时 exact 均不低于原基线，且平均实际与无缓存等效成本都降低，才通过本轮采用筛查。任一项不满足则保留原默认基线。
- 即使通过，16 个目标仍不足以证明统计非劣效或“任何五头数据都无影响”。每目标每组单次调用，temperature 0 不保证确定性；差异不全能严格归因于提示词修改。

## 结果

48 次均成功，无重试、无缺失账单、无本地完整响应缓存命中；每组 16 个原始解析响应和 16 份完整原生 usage。三组服务端缓存读取/写入均为零。实际请求审计 **48/48 PASS**：模型、温度、low、输出 Schema、三张图的字节哈希和顺序、detail 均符合冻结规范。

本轮原生标签覆盖：Instrument 4/7 类、Verb 5/10 类、Target 5/15 类、IVT 11/100 类（含 null）、Phase 3/7 类。五头 GT 均有效，不代表覆盖所有类别。16 个共同成功目标与全部目标集合相同。

## 决策与限制

两个候选都不采用为默认版本。schema_only 未通过 Target/IVT F1 门槛；tuned 未通过 Verb/Target/IVT F1 门槛。完整字段检查全部通过，不能推导“删重复说明无影响”。上轮建议只能作为实验假设，本轮结果不支持直接替换。

本次精调同时包含空字段清理和证据规则重写，不能由 tuned 对 schema_only 的差异单独确定究竟哪一句规则导致变化。每个目标每组只有一次调用、仅四个开发视频，不能证明重复 Schema 在普遍情况下必然有益或有害。没有独立标注依据时，不继续根据这些 GT 改写 grasp/retract 或解剖类别规则。

若下一步继续研究，应将低成本策略和语义改进分别验证：minimal 保持原提示词独立对照；动作/靶点定义或图像证据的改进需要更充分且与调参分离的样本。当前没有新的付费实验已被启动。
