# 接触观察步骤加入候选模板：固定 H0 的成对实验

日期：2026-09-09。独立实验，不覆盖默认入口、历史最佳结果、同学交付包或上一轮源码。

## 冻结协议

实验只改变单模型补候选输入：在原 JSON 后追加 `private_contact_audit`。原有学术用途说明仍是第一个字段，H0 答案、候选池、图谱提示、完整本体、类别边界、三张因果图、模型/路由/reasoning/温度、输出 Schema 均保留。因保留原有 H0 与图谱，**本轮不是盲预测**，不能与同学的盲 H0 实验混称。

新增步骤要求模型先检查当前图的每个器械尖端和直接接触组织，再检查历史中的可见运动，确认同一器械—动作—组织构成真实关系，最后与原候选/图谱比较，只提出有视觉支持的遗漏 ID。邻近组织、阶段常见组合、传递形变不能直接证明关系。不要求输出中间思考或观察文字，也不能证明模型实际遵循了这些内部步骤。

输入模板：[contact_first_candidate_v1.json](../src/surgical_agent/research/verification/prompts/contact_first_candidate_v1.json)。接入函数：[contact_first_candidate.py](../src/surgical_agent/research/verification/contact_first_candidate.py)。独立入口：[run_contact_first_candidate_trial.py](../scripts/run_contact_first_candidate_trial.py)。该模板仅由本实验入口加载。

输出仍为 `instrument`、`verb`、`target`、`ivt` 四个列表，新增上限分别为 2、2、2、4；不增加解释、分数、Phase 或最终修改指令。候选池仍由 H0＋提案＋必要组件构成，再用原五模型审核和均分 4 的 Python 局部接纳。没有启用收紧 Verb、争议关系复核、额外轮次、Tracker、Gate 或 Phase 修复；Phase 各版固定沿用 H0。

13 项针对性测试和 Ruff 通过，覆盖只新增一个输入字段、输入不变性、候选上限、失败回退、相同请求共享包括失败回答、不同池不复用票、Phase 不变、缺失 GT mask、禁止额外 H0/重试，以及图谱提示归档后的文本顺序恢复。输入冻结时还逐目标核对 control 与上一轮提案请求完全相同，并核对保存/重载后的两组请求一致性；付费输出封存后从原始回答重放，再进行独立计数和 GT 评分。

## 候选与审核具体发生了什么

| 任务 | GT 出现项 | control 正确/错误候选 | contact_first 正确/错误候选 | 候选覆盖率变化 |
|---|---:|---|---|---|
| Instrument | 37 | 29 / 8 | 29 / 8 | 78.38% → 78.38% |
| Verb | 39 | 24 / 28 | 25 / 25 | 61.54% → 64.10% |
| Target | 34 | 20 / 26 | 19 / 26 | 58.82% → 55.88% |
| IVT | 40 | 16 / 48 | 16 / 46 | 40.00% → 40.00% |

新模板并未提高完整 IVT 覆盖：新增覆盖两个正确 IVT 出现项，也漏掉原模板提出的两个，净值为零；两组都漏掉 24/40。错误 IVT 候选少了两个，最终错误 IVT 却从 32 增至 35。最终正确 IVT 均为 10，说明单看候选总量和最终 TP 均不足以解释效果。

**1. 新提示没有稳定分清动作与直接目标。** `VID31_78851` 原模板没有补充 `grasp`，新模板提出了 `grasp` 和 `grasper/grasp/gallbladder`（IVT 7）。新组五席对两项都给 `[4,5,3,5,5]`、均分 4.4，随后按原规则接纳。但 GT 是含 `grasper/retract/gallbladder` 的集合，没有新增这两项，因此各增加一个假阳性。原始指令已要求检查同一关系，但指令本身没有提供额外可验证的观察证据。

`VID96_23576` 新模板又提出 `hook/dissect/cystic_plate`（IVT 59），IVT 和 Target 的均分均为 4.2，被接纳为错误关系和错误 Target。该帧 GT 为 IVT 7、58，Target 为 0、2，并非新加的 cystic_plate。由此可以确认类别判断与 GT 不符；不能仅由这次调用断言画面一定足够清楚或 GT 有误。

**2. 收少候选也丢掉了正确答案。** `VID103_23751` 原模板提出正确 IVT 7 和 Verb 0，审核均分均为 4.6，最终接纳。新模板没有提出它们，后续审核根本没有机会选中。`VID31_49751` 新模板不再提出错误 IVT 7 和错误 Verb 0，这是收益；但它同时丢掉了独立正确 Target 0，而本系统的 Target 是独立任务，不能因为关系错误就认定目标也错误。

**3. 候选池变化会伴随审核判断变化，旧错误可能因此留下。** `VID103_23751` 的错误旧 IVT 79 在 control 均分 1.8，被删除；新组变成 2.2，按原来的 ≤2 删除规则而被保留。这里没有新增代码把 2.2 算错，而是对相同旧标签的审核分数跨过了接纳边界。

`VID23_19651` 的旧错误 IVT 17，在 control 均分 1.4 被删除；新组 GPT 用局部观察给否定，按已有规则不能证明整帧不存在，于是该票无效、均分为空，保留 H0 的 IVT 17。它仍需要 Verb 1，因此即使 Verb 1 的新组均分为 2.0，组件保护规则也将这个动作一并保留。这是原有保留/依赖规则的限制，不是本次加模板时发生了意外全头重建。

**4. 有局部收益，但不足以抵消误改。** `VID103_10676` 两组都提出正确 IVT 7；control 的 IVT 均分 3.6、Verb 均分 3.8 未通过，新组两者均为 4.2 而通过，新增一个正确 IVT 和正确 Verb。由于候选池不同需要重新调用审核，无法将这个分数变化完全归因于视觉检查步骤；它也包含上下文变化和重复调用波动。

汇总 IVT 差异：新组比 control 新接纳两个错误 IVT、多保留两个 H0 错误 IVT、少接纳一个错误 IVT，最终假阳性净增 3；正确 IVT 则一增一减，TP 净值不变。详细逐项链路、原始分数和候选身份保存在 `independent_diagnostics.json`。

新增覆盖的两个正确 IVT（`VID103_35076` 的 60，`VID96_23576` 的 7）最终均未通过审核，分别存在无效意见或很低的视觉评分。候选提出与审核选中仍是两个需要分别验证的环节。

本轮没有接口失败，但不是每条审核意见都有效。control 共 995 条逻辑候选评分，932 有效、63 无效；新组共 970 条，909 有效、61 无效。回看归一化前原因，control 是 60 条局部否定不足、3 条评分与判断矛盾；新组分别为 59、2 条。归一化后的空项显示 SCHEMA_INVALID，不能把它们全归因于 JSON 语法或网络失败。共享面板的意见分别用于两组评分，不能当成独立模型重复实验。
