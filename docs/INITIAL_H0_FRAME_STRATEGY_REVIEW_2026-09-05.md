# 初始联合预测的帧策略：联网复核与候选排序

日期：2026-09-05。本轮只复核本地证据并联网研究，没有付费 API 调用、训练或默认 Pipeline 修改。接续用户“先解决初始预测与帧的问题，不要迎合已有想法”的要求。

## 判断

在现有 Training/Validation 仅有 1 fps PNG、主识别使用单次 API 的条件下，首选待验证候选为 **六张真实因果图片，覆盖过去五秒，每秒选择一个目标，只联合预测末帧五项标签**。正常输入的源帧编号是 `[t-125,t-100,t-75,t-50,t-25,t]`，下一目标为 `t+25`，窗口重叠五张图片。

这是一项有手术任务文献支持的初始选择，尚不是实测获胜方案。对“六图一定胜过当前三图”的信心中低，不提供没有依据的提升百分比。若配对试验没有稳定收益，应保留更便宜的三图，甚至检查单帧是否已足够。

## 论文依据及反证

1. **RiT（Rendezvous in Time）**：同为器械/动作/靶点/IVT 识别；从 1 fps 序列构造六图因果窗口，监督和预测末帧。4/6/8 图消融中六图最好，但该消融使用 RDV 划分，不能混成主五折结果。主五折 RDV→RiT 的 Verb AP 为 62.0→64.0，IVT AP 为 29.4→29.7；grasp、retract、dissect 没有改善。它训练了时序注意力，并没有把六张图片直接发送给通用 API，也没有验证 Phase。[原文，§3.4、§4及Tables 1/2/4](https://arxiv.org/html/2211.16963)

2. **Surgical instrument-tissue interaction recognition with multi-task-attention video transformer**：帧数/采样率消融支持其 CholecT45-Vid 设置下的 16 图@6 Hz，端点跨度约 2.5 秒。采样选择也受短片段长度限制。其数据从稳定事件切成片段，将每秒标签延展到该秒原帧；CholecT45-Vid 含55种triplet，按整段分数评估。这支持密集运动信息值得研究，不能当成 Track20 全100类、因果末帧 API 的最优参数证明。[原文，Dataset creation、Experimental setup、Ablation studies](https://link.springer.com/article/10.1007/s11548-025-03546-3)

3. **TempCompass（ACL Findings 2024）**：用静态内容类似、时间关系不同的对照视频检验时序能力，发现被测多模态模型存在明显不足。它支持加入历史信息有效性诊断，不能证明当前使用的 Qwen 模型一定不能理解时间。[原文](https://aclanthology.org/2024.findings-acl.517/)

4. **TargetFusionNet**：通过实例分割与靶点相关空间融合改善手术三元组识别，提示接触组织识别也需要空间区分能力。它是监督训练路线，不能将其收益解释成 API 裁剪或增加帧数的预期收益。[原文](https://arxiv.org/html/2511.00643v1)

5. **SlowFast**：低帧率分支处理空间语义、高帧率分支处理运动，是不同时间尺度可以互补的机制依据。它是训练过的双路视频网络，不能声称把两组不同采样率图片拼进一个 API 请求就是 SlowFast，或一定超过均匀六图。[ICCV 2019 原文](https://openaccess.thecvf.com/content_ICCV_2019/papers/Feichtenhofer_SlowFast_Networks_for_Video_Recognition_ICCV_2019_paper.pdf)

本次优先采用同任务证据。此前列举的长视频问答/流式描述论文的任务、训练方式和输出时刻不同；不再拿它们的记忆容量或视频总帧数给本项目硬定窗口。

## 本地证据如何限制建议

- 官方区分原始视频25 fps、标注1 fps；这决定哪些目标有可评分真值，不规定模型必须只看1 fps。[官方说明](https://github.com/CAMMA-public/cholectrack20)
- 本地 Training/Validation 目前只有稀疏PNG；Testing 有原始MP4。不能插值生成中间画面后声称恢复了真实运动，也不应为了调采样参数继续反复利用 Testing。缺少密集开发视频使高帧率候选暂时无法公平定型。
- 已有 VID06 六目标密度试验，一秒三图与一秒25图的 IVT micro-F1 分别50%与48%，25图费用为三图的2.54倍。六目标的标签相同、时间相邻，且没有多次采样控制API随机性；既不能证明密集采样普遍无效，也不能证明五秒六图有效。
- 该密度试验的三图是约一秒跨度，**不是当前正式 `[t-50,t-25,t]` 的两秒三图**。两者不能混称同一基线。
- 当前错误中有持续的靶点混淆；增加时间范围可能补充遮挡/交互信息，但不保证模型认得相似组织。因而预期仅靠改帧数量获得大幅IVT跃升的依据不足。

本地依据：[密度实验](WINDOW_DENSITY_PAPER_REVIEW_AND_SMOKE_2026-09-05.md)、[数据完整性与方法报告](TRACK20_DATASET_AND_METHOD_RECOMMENDATION_2026-09-05.md)、`artifacts/preflight/track20_scheme_audit_20260905_v4.json`。

## 候选排序

| 候选 | 当前判断 |
|---|---|
| 六图@1 fps，过去五秒 | 当前数据/API约束下最值得先测；直接同任务证据较强，但API迁移效果未知 |
| 三图@1 fps，过去两秒 | 已有基线；六图若不稳定获益就保留它 |
| 单张当前图 | 必须加入的低成本对照；检查额外历史是否真的有用 |
| 约16图@6 Hz，过去2.5秒 | 有密集手术视频模型证据；待取得Training/Validation真实原视频后测试，不直接采用论文分数或标签延展 |
| 25张相邻原帧，过去0.96秒 | 当前不优先；范围短、成本高，已有小样本没有IVT增益 |
| 稀疏长历史＋密集近历史 | 合理研究假设，尚无证据在本API上优于简单六图，暂不加入首轮 |

输入始终按真实时间排序、明确最后一张为目标，提示只输出目标时刻标签；不把窗口内发生过的动作并集当作末帧答案。保留当前图像清晰度，所有比较使用同一图像编码与detail规则，不同时改变裁剪、模型、提示、Tracker或Repair。正式工厂仍固定三图，六图候选需独立入口。

目标步长用25个原帧，即一个1 Hz采样点。对于无跨窗口状态、同模型同提示的API，共同目标上的输入不会因为额外预测中间帧而变好；步长1主要增加调用及没有原生GT的输出。这个结论不外推到连续更新隐藏状态的训练模型。1 Hz输出目标密度也不等于API能在一秒内返回。

## 最小可判别试验（提案，尚未执行）

调整此前仅在VID110做三组试验的建议：先用有完整IVT监督的四个Training视频 VID103、VID23、VID31、VID96，每视频20个按时间分散的目标，共80个。同一批目标做四组：

| 组别 | 相对目标的秒数 | 目的 |
|---|---|---|
| A | `[0]` | 单帧基线 |
| B | `[-2,-1,0]` | 当前三图基线 |
| C | `[-5,-2,0]` | 固定三张，将历史范围拉长 |
| D | `[-5,-4,-3,-2,-1,0]` | 相同五秒跨度，增加历史采样 |

B/C 比较固定张数的两种时间布局；C/D 比较相同端点跨度的两种密度。它们不单独证明模型利用了运动或时间方向；若D获益，再做当前帧重复、历史替换/顺序诊断，并如实标记对照时间，避免伪造图像来源。

本地审计中完整六图历史且目标IVT有效的数量分别为1,474、1,150、3,534、1,004，足以准备上述样本。选择只用媒体、时刻与有效性mask，不根据GT类别或既有模型错误挑目标，预测完成后评分。VID31的监督是帧级sidecar，没有实例框；报告按视频分开，并单列其来源。完整历史条件仅限定这个诊断试验；最终评测必须保留开头/缺口目标并使用预先固定的短窗策略。

主要比较五头语义micro-F1、整组正确率、逐视频差异、API失败、成本与延迟；IVT为主要选择指标，Verb/Target用于解释。不能把结构合法率当精度。四个视频仍不足以建立总体统计结论；冻结一个候选后再用Validation确认，记录VID110已有多次开发使用的事实。

费用计划为 **80目标×4组＝320次调用**。按此前本地账单粗估约 **5–10美元**，不是当前报价或保证；真正执行前核对模型可用性、价格和首批费用，再确定调用/费用停止规则。当前没有请求级美元硬上限保证，不能把本地调用前余额检查说成供应商硬预算。本轮实际付费调用为0。

如果三图、六图均不优于单帧，或相同靶点错误持续，不再把增加帧数作为已获支持的修复方向。后续应独立检查动作标注语义、实际上传图像细节和领域视觉能力；如转向训练，需要手术视觉/时序特征与末帧分类监督，Tracker的器械框重训本身不等于训练五头语义模型。
