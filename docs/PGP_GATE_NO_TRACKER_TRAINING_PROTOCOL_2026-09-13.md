# 无 Tracker 的 PGP-Gate：本次训练协议

用户要求：冻结已经训练好的 Tracker，只训练不接入 Tracker 的 Gate，然后查看效果。旧权重仅在影响新训练时允许删除；本实现不加载旧权重，输出目录独立，因此全部保留。

本协议在本次新模型拟合和新结果产生前写入，数据已被多次用于方案开发，不声称独立预注册验证。

## 范围与方法

- 使用原始首轮有观测结果的 6,059 条 Training 行（VID103、VID23、VID31、VID96）。不把其他 1,313 条缺失结果填成中性；不把重试/语法恢复结果与首轮 Qwen 混合。
- 先验 + Qwen 初审 + Gate 是一个 PGP 模块。本次只有无 Tracker 版本，Tracker 的 full/五折权重及预测只做哈希冻结，不载入训练或推理。
- 移除原特征 schema 中所有 `tracker_*` 列，而不是带着非零可能性运行旧权重。其余 H0/cheap 特征、候选池、Qwen 自身评分与有效性保持已有定义。当前阶段的全体审核评分、最终输出和 GT 不得进入 Gate 输入。
- 四个动作：保留 cheap；只继续交互四头；只继续阶段；两部分都继续。未选择分支必须逐字段保留 cheap。
- 两次 Qwen 及前置共五次逻辑调用。选择的分支复用 Qwen，只请求剩余席位；停止证据只允许使用已查询评分。没有选择升级仍支付初审费。
- 四个轻量逻辑回归评分头（两分支各 help/harm），仅 fitting 数据进行 video-weighted standardization，LogisticRegression C=1、liblinear、class_weight=balanced、seed=3407；单类别时显式常量。不加载任何旧 Gate 权重。

## 预先固定的监督与选择

主方案为 semantic_benefit_original_harm：归并口径分支 F1 正收益监督 help；原口径分支 F1 负收益或 FP+FN 增加监督 harm。F1 按头求均值，空集合对空集合为 1。两项分数分别设阈值，高 help 不能抵消超标 harm。

只做两个预声明监督消融：original（两项均原口径）、merged（两项均归并口径），均为不含 Tracker 的 PGP；它们不是两套 Tracker 版本。所有策略选择与最终验收一律用原口径。

每分支 help 下限和 harm 上限均取 `[-0.01, 0.25, 0.5, 0.75, 1.01]`，每分支 25 种、完整策略 625 种，包含始终与从不升级。相同 Gate 的两分支联合评估完整策略。

外层留一 Training 视频；其余三视频内层留一生成校准预测。标准化、模型和阈值不使用外层视频标签。先满足：整体 F1 >= max(cheap, full)、错漏 <= min(cheap, full)、每个内层视频不差于 cheap、确有正向效果、调用少于相同 Qwen/停止全继续；再选调用最少，依次以最差视频 F1 增量、整体 F1、错漏和固定候选编号破同分。不根据本次外层结果修改候选或容差。

无可行策略时，门槛全跳过并明确标 INFEASIBLE_CONSERVATIVE_FALLBACK，仍计五次初审前置费用。全跳过不得标成功。

## 输出、基线与验收

- H0、cheap、含先验全审核、同 Qwen 初审和停止的全继续、固定只审交互/阶段、旧整帧 Qwen Gate、新 PGP 三种固定监督。
- 同视频逻辑调用上限的随机分支对照：300 次、seed3407、30 帧连续块。它是条件化离线参考，不是匹配美元费用或独立视频置信区间。
- 每视频/每头原口径与归并口径 F1、FP+FN、动作分布、逻辑调用、已知 USD、未计价 GLM/DeepSeek 请求数；本地训练耗时，不伪造 API 推理延迟。
- 外层所有折内层可行且外层完整策略通过上述质量/成本要求，才标 conditional development pass；随机对照优势另列，不能隐去。
- 保存外层分数/动作/计数和每折模型；用四视频 OOF 选一次最终研究门槛，再在全部 Training 行拟合研究权重。后者不拥有外层未见样本，不能拿外层成绩冒充最终模型独立测试成绩。
- 模型全部 `deployable=false`，含明确 schema/源码/先验来源与阈值选择状态。不可行模型也保留但标失败，不投入运行。
- 上游先验未在 Gate 每折完全嵌套，四视频已参与反复开发；本次是有条件的离线开发评估。没有独立稳定性保证。

执行不访问 Testing/VID110、不调用付费 API、不部署、不训练 Tracker。所有旧结果保留，输出为新目录 `artifacts/training/gate/pgp_gate_no_tracker_*`。
