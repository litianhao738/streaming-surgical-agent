# Gemini 3.8 初审 PGP-Gate：全量重训结果

## 结论

6,059 帧已补采，两种 Gate 均已训练完成。**不替换旧 Qwen 默认方案**：新版本相对自己的全审核方案能减少调用，但相较旧默认，五头平均 F1 更低、调用更多、估算美元成本更高。Tracker 开启和关闭版本均未通过预先规定的外层 90% 审核增益保留目标。

新权重可通过兼容性检查并用于 Training 研究回放，但“能够加载”不代表效果验收通过。配置状态已更新为 `TRAINED_NOT_SELECTED_RESEARCH_ONLY`，旧默认指针未变。

| H0 | 58.4914 | 40241 | 6059 | 26.45 |

| 旧 Qwen Gate，当前默认 | **61.6989** | **36150** | **37157** | **86.41** |

美元成本结合历史分阶段均值和本次逐帧 Gemini 初审费用，不是此次实际重复运行整个 pipeline 的账单。GLM、DeepSeek 另按请求数量记录，本地 Tracker 算力成本未包括在美元列中。

Tracker 开启版相对新歧义保护全审核，减少 **13.57% 调用、9.76% 已知美元成本**，但只保留 **82.66%** 的审核 F1 增益；关闭版分别为 **10.75%、7.84%、87.63%**。两版在四个视频的聚合 F1/错误数上均不差于便宜答案，但都未达到 90% 的外层保留目标。

旧默认此前也仅保留了约 83.66% 的审核增益，并未满足严格的外层 90% 目标。保留旧默认是因为此次同批比较中它的 F1、错误数和成本均优于新训练版本，不表示旧默认已获得独立新视频上的精度保证。

## 原因分析

**初审成本先上涨了。**所有帧必须支付的 H0、候选建议、初审前缀，估算成本由旧方案的 $48.04 上升至 $72.70。即使后面少问一些审核员，也先承担了更高的固定成本。

**现有审核及歧义保护规则与新模型的组合改变了收益。**歧义保护后，会改变便宜答案的帧由 509 降至 267；按逐帧 FP+FN 判断，改好帧由 330 降至 192，改坏帧由 158 降至 65，净减少错误由 433 降至 264。变化少了，伤害也少了，但可获得的净修复收益同样减少。

不能把这个现象简单解释成“Gemini 更差”：新完整审核不做歧义保护时 F1 为 61.7159；套用原来的歧义保护后降到 61.6468，同时总错误由 36933 降到 36258，说明原保护策略在新模型下的 F1/错误数取舍发生了变化。此次没有根据结果重新调整保护规则。

**重新拟合并没有改善留出排序。**在同一套新标签下，旧 Gate 直接迁移的 AUC 为 0.7641；重训后 Tracker 开启为 0.7322，关闭为 0.7471。为达到训练视频内的精度要求，阈值选择放行了更多帧：开启版审核 4,700 帧，关闭版审核 4,942 帧。数据支持“本次重训的跨视频筛选能力不足”这一判断，但不能据此断言所有 Gemini 模型或所有训练配置都会如此。

## 最终权重的运行诊断

最终全量拟合权重在同一训练缓存上的回放中：

- Tracker 开启：53,118 次调用，比新全审核的 53,314 次仅少 **0.37%**。
- Tracker 关闭：53,301 次调用，仅少 **0.024%**。

这说明此次校准阈值应用到最终拟合模型时接近全放行，未形成有实用价值的成本优势。这是训练集上的运行诊断，不是独立泛化评估，更不能拿它代替上面的外层结果。

## 采集、验证和保留状态

- 新增逻辑请求 6,059 次，只调用 Gemini 3.8 交互初审；5,942 条成功解析，117 条失败或拒收均保留，无自动重试。
- 总账本占用 **$26.258223**，低于 $40 上限。其中 6,058 次有服务端费用记录，1 次按未知费用的保守预留计入。准确拆分见 `runtime_audit.json`。
- 全量 6,059 帧重建完成，精确早停与完整审核的输出差异为 **0**。
- 冻结 Tracker 覆盖全部 6,059 帧，未重新训练；旧结果和旧权重均保留。
- 未访问 Testing/VID110，未部署。训练及所有后续分析均为本地计算。
- 这仍是四个反复用于开发的 Training 视频；上游先验/Tracker 未随 Gate 外层划分完全重新嵌套，不能称为独立论文终测。

## 文件和入口

训练目录：`artifacts/training/gate/pgp_gemini38_training_20260913_r1`。

- `report.json`：全部外层结果、内层阈值选择与基线。
- `diagnostic_analysis.json`：收益、伤害、AUC 和前缀成本分析。
- `build_receipt.json`、`training_receipt.json`、`runtime_audit.json`：数据、训练和加载回放验证。
- `models/tracker_on_model.json`、`models/tracker_on_estimator.joblib`：Tracker 开启权重。
- `models/tracker_off_model.json`、`models/tracker_off_estimator.joblib`：Tracker 关闭权重。

无需付费的状态检查：

```powershell
.venv-p2\Scripts\python.exe -B -X utf8 scripts\run_pgp_pipeline.py info --variant tracker-gemini38 --tracker on
.venv-p2\Scripts\python.exe -B -X utf8 scripts\run_pgp_pipeline.py info --variant tracker-gemini38 --tracker off
```

两种权重各自绑定其训练的 Tracker 模式，不将一个权重直接冒充两种模式都已验证。全量“不重训迁移”对照另存于 `artifacts/preflight/pgp_gemini38_transfer_all_20260914_r1`。
